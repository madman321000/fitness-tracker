# Fitness Tracker Django Boilerplate

This repository contains a minimal Django project with a single route that
responds with `Hello, world!`.

## Getting started

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python fitness_tracker/manage.py runserver
```

Then visit http://127.0.0.1:8000/ in your browser to see the message.
